# BRavo concept demo

Rama aislada para validar la experiencia inicial de BRavo.

## Hipótesis del demo

BRavo no empieza por un catálogo: empieza por la necesidad del usuario. BR Companion ayuda a convertir una intención en rutas comprensibles y el usuario conserva la decisión.

## Recorridos incluidos

- Empezar a entrenar
- Resolver una necesidad legal
- Mejorar un negocio
- Exploración por intención
- Capa de comunidad

Este demo no tiene backend, pagos ni recomendaciones reales. Su objetivo es validar dirección de producto y UX antes del MVP.
